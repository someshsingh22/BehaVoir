\caption{Overview of the benchmark. Given a research question taken from a published paper and resource
constraints, the \emph{Dataset Discovery Agent} explores a fixed Reddit snapshot and its documentation to construct
a dataset. The generated dataset is scored by downstream utility: in the \emph{Author Evaluation Harness}, a
submission agent trains and evaluates on it with the authors' released code and guidelines; in the \emph{Open
Evaluation Harness}, a submission agent runs our standardized pipeline on both the generated and the authors'
original dataset under identical conditions.}
